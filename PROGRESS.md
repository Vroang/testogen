## Статус: собран, тег v48 отправлен, ждёт проверки пользователем

## Что сделано
- Принцип: телефон — МАСТЕР, облако/веб — реплики. Push уходит
  тихо; всё входящее из облака применяется только после
  подтверждения пользователем.
- DataStore (SettingsRepository): ключи last_sync_timestamp и
  pending_changes_hash (отпечаток отменённого набора).
- CloudSyncRepository (новый файл):
  - syncWithCloud(showPrompt, ignoreDeclinedHash): тихий push
    (учебники + вопросы + причины) → detectCloudChanges →
    пусто/отменено/нужнo подтверждение;
  - detectCloudChanges: расхождения по cloudId — новые,
    изменённые (только если локальный synced; pending считается
    новее), удалённые (только synced; pending игнорируется),
    новые/удалённые учебники, счётчики причин; записи из
    очереди pending_deletes не считаются изменениями;
  - applyCloudChanges: применяет подтверждённое (вставить/
    обновить/удалить вопросы, причины, учебники), сбрасывает
    хэш и пишет last_sync_timestamp.
  - CloudChanges.isMassDeletion: удалено ≥ 10 вопросов.
- UI:
  - CloudChangesDialog: «Изменения из веб-версии» со списком
    (новые с текстами до 3 + «и ещё N», «старый → новый»,
    счётчики удалений/учебников/причин); при массовом удалении
    (≥10) — заголовок «⚠️ Массовое удаление» и список
    удаляемых вопросов;
    кнопки: «Отменить» (запоминает хэш, Toast «Изменения
    отложены…»), «Подробнее», «Применить»;
  - ChangesDetailScreen (маршрут changes_detail): полный
    список по разделам + «Применить» / «Отменить»;
  - диалог рисуется глобально в AppNavigation (виден с любого
    экрана).
- Триггеры syncWithCloud(showPrompt = true): старт приложения
  (после входа), onResume (не чаще раза в 5 минут), открытие
  вкладки «Ручной ввод», кнопка «Проверить сейчас» в
  Настройках. Автоподтягивание из шага 31.1 заменено этим
  механизмом (подтверждение вместо тихого применения).
- Настройки: время последней синхронизации, «Проверить
  сейчас», «Применить отложенные изменения (отменено ранее)»
  (появляется, когда есть отменённый набор).
- Банк вопросов: в шапке — спиннер во время синхронизации и
  серый «!» при отложенных изменениях (тап — показать диалог
  снова).
- app/build.gradle.kts: versionCode = 48, versionName = "0.32-step32".
- Push-логика, учебники, каскад, автообновление — не тронуты.
  Новых библиотек нет.
