## Что сделано
- ЧАСТЬ 1 — парсинг (TextbookRepository):
  - PDF читается ПОСТРАНИЧНО (PdfBox, страница за страницей);
  - splitParagraphs получает список страниц и для каждого §
    определяет startPage/endPage (страница начала и страница
    конца содержимого; для DOCX/TXT — заглушка 1/1);
  - title: первая содержательная строка после «§ N» (номер
    «4.» в начале срезается), до 100 символов; в Supabase —
    колонки title/start_page/end_page (SQL у пользователя);
  - ParagraphInsert передаёт title/start_page/end_page;
  - fetchParagraphText заменён на fetchParagraphs (все
    параграфы по возрастанию номеров, DTO ParagraphRow с
    title/страницами);
  - buildGenerationText: режим параграфов — выбранные §
    целиком; режим страниц — §, пересекающие диапазон, с
    приближённым пропорциональным срезом текста внутри
    параграфа (поэтапного текста страниц в БД нет);
  - Room НЕ менялся: параграфы в Room не кэшируются (только
    метаданные учебника).
- ЧАСТЬ 2 — экран «Выбор диапазона» переработан:
  - блок «Тема вопросов» (пусто → автотема: имя учебника +
    выбранные § или «, стр. X–Y»);
  - переключатель «По параграфам / По страницам» (страницы —
    только для PDF, иначе Toast);
  - режим параграфов: быстрый диапазон «От § / До § /
    Выделить» + сворачиваемое «Содержание (N)» со списком
    галочек: «§ 4. Реформация» + «стр. 40–65» (для PDF);
    по умолчанию ни один не выбран; при 0 выбранных кнопка
    неактивна; «Выделить» автоматически разворачивает список;
  - режим страниц: «От стр. / До стр.» + превью «Будут
    включены: § 4, § 5, § 6 (страницы 45–50)» либо «В этом
    диапазоне нет параграфов»;
  - параметры: количество −/+ (1–50, по умолчанию 10),
    мультивыбор сложностей;
  - генерация через существующий каскад (операция «pdf»,
    попадает в «Журнал ИИ»), дедупликация, topic из поля.
- ЧАСТЬ 3 — содержание доступно прямо на экране диапазона
  (сворачиваемый блок, по умолчанию свёрнут).
